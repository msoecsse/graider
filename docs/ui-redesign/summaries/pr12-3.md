# PR12-3: bulk roster section summaries IPC read

## Summary

Added one registered-course Electron IPC read, `getRosterSectionSummaries`,
for all configured sections in a selected term. It is a single bulk request,
not a renderer loop over `getRosterForSection`.

The implementation follows the established `src/**/*-context.ts` →
`ui/scripts/build-template-sync.mjs` → `ui/dist-electron/*.cjs` → Electron
service `require()` boundary. The new context parses each existing roster with
PR12-2's `parseAndValidateRosterCsv` and computes counts through the shared
canonical roster-summary helper also used by `roster-loader.ts`.

Each section is independently `ready`, `missing`, or `invalid`. `ready`
includes `studentCount`, `activeStudentCount`, `droppedStudentCount`, and
`holdStudentCount`; a missing roster is explicitly `exists: false`; an invalid
roster has diagnostics and no fabricated counts. A term configuration problem
returns the structured `term_config_error` result.
